# 模板：文献矩阵

一行一篇，不合并。字段缺就留空并标 `[未验证]`。

```markdown
| # | 作者（年） | 标题 | 期刊/会议 | DOI | 设计 | 样本 | 方法 | 主要结论 | 局限 | 与 RQ 关系 | 证据等级 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  |  |  |  |  | A |
| 2 |  |  |  |  |  |  |  |  |  |  | B |
```

## 填写规则

- DOI 必须可解析；没有 DOI 的写稳定 URL。
- "与 RQ 关系"写：支持 / 反对 / 部分支持 / 背景。
- 证据等级见 `references/evidence-levels.md`。
- 只读了摘要的，在"局限"里写"仅摘要"。
- 同一研究有多个报告时合并到一行并注明。
