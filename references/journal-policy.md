# 期刊/会议政策核查

## 必须核的项

| 项 | 在哪查 | 核不到时 |
|---|---|---|
| 收录范围 / 文章类型 | 官网 Aims & Scope、Author Guidelines | 标未验证，不假设"应该收" |
| 字数/页数/图表数限制 | Author Guidelines | 标未验证 |
| 引用格式与模板 | 官网模板下载页 | 用通用格式并注明"待按模板调整" |
| AI 使用披露要求 | 官网 AI Policy / Editorial Policies | 标未验证；给通用声明并提示需人工确认 |
| 伦理与知情同意要求 | 官网 Ethics / Human Subjects 政策 | 标未验证 |
| 数据与代码可用性 | Data Availability 政策 | 标未验证 |
| 开放获取与费用（APC） | 官网 APC 页面 | 标未验证，不写具体金额 |
| 预印本政策 | 官网 Preprint Policy | 标未验证 |
| 影响因子 / 分区 | JCR、中科院分区（商业库，需订阅页） | **标未验证，正文不写具体数值** |

## 核查步骤

1. 打开 venue 官网 → 找 Author Guidelines。
2. 分别搜 "artificial intelligence"、"AI"、"generative" 找 AI 政策条款。
3. 记录页面 URL + 抓取日期 + 关键条款原文短引（≤2 句）。
4. 政策有版本号/生效日期 → 一并记录。
5. 页面打不开或需登录 → 标 `未验证`，在核查表写"需机构访问"。

## 影响因子与分区的特别说明

- 影响因子、分区是商业数据库产品，公开网页常只有二手转述。
- 没有官方页面时：正文写"该刊影响因子/分区需以 JCR/中科院分区官方查询为准（未验证）"。
- 不要用聚合网站的数值撑结论，也不要把"Q1"当公认事实。
