# 写作质量检查

## 机器味清单（逐条扫）

| 模式 | 例子 | 改法 |
|---|---|---|
| 空泛抬升 | "具有重要的理论意义和现实意义" | 说清对谁、在什么决策上有什么用 |
| 三段式排比 | "不仅…而且…更是…" | 拆成具体因果句 |
| 无源断言 | "研究表明…"（无引用） | 要么给来源，要么删 |
| 万能过渡 | "综上所述""值得注意的是" | 直接说结论 |
| 形容词堆叠 | "显著地、极大地、深刻地" | 给数字或去掉 |
| 同义反复 | "目的是为了" | 删一个 |
| 过度对冲 | "可能或许在一定程度上" | 只留一个限定词 |
| 结构对称癖 | 每段都是"首先/其次/最后" | 按论证需要分段 |
| 术语漂移 | 同一概念三种叫法 | 统一术语表 |
| 引用装饰 | 一句话挂 5 篇引用但都不具体 | 一句一证或合并 |

## 断言强度阶梯

按证据强度选词，不许越级：

1. 数据直接支持 → `表明` / `显示`
2. 多来源一致 → `一致显示` / `综合来看`
3. 单一来源 → `某研究（作者, 年）报告`
4. 间接推断 → `提示` / `可能`
5. 无来源 → 不写，或标 `[未验证]`

反向也成立：证据强就不要用"可能"削弱它。

## 风格校准（用户有旧作时）

1. 读 2–3 篇用户旧作，提取：句长分布、第一人称使用、术语偏好、段落长度。
2. 写一段 150 字样例给用户确认，再展开。
3. 不模仿到失去准确性；风格让位于事实。

## 章节自检

- **引言**：问题→缺口→本文做什么→贡献，四步齐全；不要在引言里写结论细节。
- **方法**：可复现到"别人能照做"；参数、数据、工具版本齐全。
- **结果**：只说看到什么；解释放讨论。
- **讨论**：结论 ≤ 证据；给出替代解释与局限。
- **结论**：不引入新事实；回应引言承诺。

## 交付前 10 问

1. 一句话论点是什么？
2. 每个论断有证据吗？
3. 引用与文献表对得上吗？
4. 有没有编造的数字/DOI？
5. 相关性有没有写成因果？
6. 结论有没有超出样本？
7. 反例处理了吗？
8. 方法能被照做吗？
9. 术语统一吗？
10. AI 使用披露了吗？
