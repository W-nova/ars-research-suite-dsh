# 证据等级（evidence levels）

用来决定"这条来源能撑多重的结论"。

| 等级 | 来源类型 | 能支撑什么 | 不能支撑什么 |
|---|---|---|---|
| A | 同行评审原始研究、官方数据集、标准/指南原文、出版社 DOI 页 | 具体事实、数字、方法细节 | 跨领域的普适结论 |
| B | 系统综述/Meta 分析、权威机构报告、教科书 | 领域共识、效应范围 | 单篇研究的具体数字 |
| C | 预印本、学位论文、会议海报、行业报告 | 线索、待验证假设 | 当作已确立事实 |
| D | 媒体报道、博客、百科、AI 生成内容、个人记忆 | 背景、寻找线索 | 任何事实性断言 |

## 使用规则

1. 正文的硬数字优先用 A；A 拿不到才退到 B，并说明"综述层面"。
2. C 级来源必须标"预印本/未经同行评审"。
3. D 级只能出现在"背景介绍"或"线索"里，且要标"据媒体报道，未核实"。
4. 同一事实有 A 与 C 冲突时，以 A 为准，把 C 作为"存在不同报告"写出来。
5. 用户提供的未发表数据算 A-，但来源栏必须写"用户提供，未独立核验"。
6. 不要把"很多文章都这么说"当证据：要找一篇能代表该说法的原始文献。
